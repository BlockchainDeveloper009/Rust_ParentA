Algorithm_Problems.md
Common algorithmic problems asked in Rust coding interviews at MAAGA companies typically test your understanding of both Rust and core computer science concepts. Here are problem categories and specific examples frequently encountered:

***

### 1. **Array and String Manipulation**
- Find duplicates, majority elements, or missing numbers.
- Reverse words or entire strings.
- Substring search or longest substring without repeating characters.
- Two-pointer and sliding window problems.

### 2. **Linked Lists**
- Reverse a linked list.
- Detect cycle in a linked list.
- Merge two sorted linked lists.
- Linked list intersection.

### 3. **Trees and Graphs**
- Binary tree traversals (inorder, preorder, postorder).
- Lowest common ancestor.
- Number of islands (grid DFS/ BFS).
- Graph traversals (DFS, BFS).
- Detect cycles in graphs.

### 4. **Dynamic Programming**
- Fibonacci sequence.
- Climbing stairs variants.
- Coin change problem.
- Longest increasing subsequence.
- Edit distance.

### 5. **Sorting and Searching**
- Implement sorting algorithms (merge sort, quick sort).
- Binary search and variants (search in rotated array, find first/last occurrence).
- Kth largest/smallest elements.

### 6. **Bit Manipulation**
- Single number identification.
- Counting bits.
- Bitmask DP problems, subsets.

### 7. **Stacks and Queues**
- Evaluate Reverse Polish Notation.
- Min stack.
- Sliding window maximum.

### 8. **Recursion and Backtracking**
- Permutations and combinations.
- Generate parentheses.
- Sudoku solver.

***

### Why Rust is Different in Interviews:

- You must express ownership, borrowing, and lifetimes correctly.
- Efficient use of `Vec`, `HashMap`, `HashSet` and Options.
- Handling errors with `Result`.
- Often encouraged to write safe concurrent or parallel code snippets.
